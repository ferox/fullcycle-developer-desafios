## Desafio imagem Go enxuta

O desafio é publicar uma imagem no docker hub. Quando essa imagem for executada deverá ser impresso a mensagem: "Full Cycle Rocks!!". A imagem não poderá ter mais de 2Mb em seu tamanho.
